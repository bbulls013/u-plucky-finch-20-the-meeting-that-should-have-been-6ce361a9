A tiny deterministic program for the make.fun bounty
[The Meeting That Should Have Been an Email](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9).

`main.ts` writes one original one-line meeting joke to `/output/entry.txt`
(UTF-8, 92 characters, inside the 1–200 character gate). It takes no input,
uses no network, and produces byte-identical output on every run.

Run it with Node 22 or later:

```sh
node main.ts
```
